# XBeadCraft

**把喜欢的图片，变成可以照着摆豆的图纸。**

XBeadCraft 是一款基于 **MARD 221 色卡**的拼豆图纸桌面工具。导入图片后，自动匹配拼豆颜色，生成带色号、坐标和用量图例的图纸；也可以逐格调整配色，或批量替换某个色号，最后保存为 PNG。

## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 图片转图纸 | 支持 PNG、JPG、JPEG、WEBP，自动匹配 MARD 221 色 |
| 图鉴模式 | 按目标豆子数量调整尺寸，让不同造型的角色使用接近的豆子数量 |
| 自定义尺寸 | 按宽度、高度或最长边设置目标尺寸 |
| 透明背景处理 | 支持裁掉透明边缘、调整透明阈值，并用棋盘格显示空白区域 |
| 清晰的摆豆参考 | 每格显示 MARD 色号，可显示四边坐标、颜色背景和粗分隔线 |
| 逐格换色 | 点击选格，支持多选、透明格填色和连续撤销换色 |
| 按色号批量替换 | 一键选中某个色号的全部格子，统一替换为另一种 MARD 颜色 |
| 水平镜像 | 随时切换图案方向，色号文字、坐标和图例保持正常阅读方向 |
| 图例排序 | 按豆子数量从多到少，或按 A–M 颜色系列排列 |
| PNG 导出 | 保存当前图纸，包含网格、色号、坐标设置和颜色用量图例 |

## 快速开始

需要 Python 3.10 或更高版本。以下命令适用于 macOS / Linux，在终端中依次运行：

```bash
git clone https://github.com/WenxuanDuan/Xbeadcraft.git
cd Xbeadcraft
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

程序会打开独立桌面窗口。后续启动时，进入项目目录、激活虚拟环境，再运行 `python app.py` 即可。

已有本地项目时，直接进入原项目目录，无需重新克隆。Windows 用户可用 `.venv\Scripts\activate` 激活虚拟环境。

## 从图片到图纸

### 1. 选择图片与尺寸

点击「选择图片」，然后选择尺寸模式：

| 模式 | 适合的情况 |
| --- | --- |
| 图鉴模式（推荐） | 为一组角色制作豆子数量接近的作品 |
| 固定最长边 | 希望图案控制在指定的最大边长内 |
| 固定宽度 / 固定高度 | 已确定作品的横向或纵向尺寸 |

图鉴提供三档规格：**小型约 550 颗、标准约 850 颗、大型约 1200 颗**。实际用量会随轮廓、透明区域和尺寸限制有所变化，以生成结果为准。

可按需要调整格子大小、粗线间隔、透明阈值，以及颜色背景、四边坐标和透明棋盘格的显示方式。尺寸与显示设置调整后，点击「生成图纸」应用。

### 2. 调整配色

**局部换色**

1. 点击预览中的格子，蓝框表示选中。
2. 按住 **Ctrl**（Mac 也可用 **⌘**）点击多个格子；按住该键再次点击已选格可取消选择。
3. 在「替换颜色（MARD 221）」中参考色块和色号选择颜色，点击「替换选中像素」。

透明格也可以填入颜色。「清除选择」只取消选区；「撤销换色」可逐次恢复之前的换色操作。

**整种颜色替换**

在「按色号全选（当前图纸）」中选择原色号 → 点击「全选此色号」 → 选择目标色号 → 点击「替换选中像素」。

原色号列表只显示当前图纸使用的颜色及颗数。全选会替换原有选区，整批换色可一次撤销；颜色用量和图例会同步更新。

### 3. 选择方向与图例顺序

- **水平镜像**：勾选后立即左右翻转拼豆图案，取消勾选恢复正常方向。镜像状态下仍可按显示位置选格换色，修改会保留。
- **按数量排序**：图例按用量从多到少排列；数量相同时按系列及色号升序排列。
- **按系列排序**：图例按 A–M 排列，同系列按色号数字排序，例如 A1、A2、A10。

镜像和图例排序均可在生成后直接切换，无需重新匹配颜色。

### 4. 保存 PNG

点击「保存 PNG」，选择保存位置。导出采用当前预览的图案方向、配色与图例顺序，选区蓝框不会出现在图片中。

> 手动换色仅保存在当前运行中的图纸里。重新生成会清除换色与撤销记录，并恢复正常方向；关闭程序前，请保存需要的 PNG。

## 关于色卡

自动匹配与手动换色均使用项目内的 [`data/mard_221.csv`](data/mard_221.csv)，包含 MARD 221 色。程序启动时会自动加载，无需额外下载。

屏幕色块用于参考，实体拼豆会受批次、光线和屏幕显示影响，制作前可结合实际材料调整配色。

## 开发与测试

```text
app.py                  桌面程序入口
ui/main_window.py       界面、选格与换色交互
core/image_processor.py 图片处理与尺寸计算
core/color_matcher.py   MARD 颜色匹配
core/pattern.py         图案矩阵与用量统计
core/renderer/          图纸、网格和图例渲染
data/mard_221.csv       MARD 221 色卡
tests/                  自动化测试
```

在已激活虚拟环境的项目目录中运行：

```bash
python -m unittest discover -s tests -v
```

测试覆盖水平镜像、选格换色、批量替换、撤销、图例排序与 PNG 导出一致性。
